# Contributing

Bug reports and small, focused fixes are welcome. For anything larger, open an issue first.

- Branch from `main` as `fix/…`, `feat/…` or `chore/…`; one change per pull request.
- Commits follow [Conventional Commits](https://www.conventionalcommits.org/) (`fix: …`, `feat: …`), imperative mood, subject under 72 characters.
- Backend and frontend tests and lints must pass (see the Development section of the README).
- Match the surrounding code. `CLAUDE.md` explains how the code fits together.
- Contributions are accepted under the AGPL-3.0.
